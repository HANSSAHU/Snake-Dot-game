# Snake Dot Game

A classic Snake Dot Game developed using HTML, CSS, and JavaScript. Players control a snake that grows longer by collecting dots while avoiding collisions with itself and the game boundaries. The project demonstrates fundamental game development concepts, including collision detection, score management, keyboard controls, and real-time rendering.

## Features
- Classic Snake gameplay
- Responsive keyboard controls
- Real-time score tracking
- Collision detection system
- Smooth animations and movement
- Lightweight and browser-friendly

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## How to Play
1. Use the arrow keys to control the snake.
2. Collect dots to increase your score and snake length.
3. Avoid hitting the walls or the snake's own body.
4. Try to achieve the highest score possible!

## Learning Outcomes
- JavaScript game logic
- Event handling
- DOM manipulation
- Collision detection
- Animation loops
